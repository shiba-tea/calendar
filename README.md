# calendar
JavaScript制作万年カレンダー

HTML / CSS / JavaScript

制作期間：2～3日程度（以降継続して改修）

課題として制作

条件：

　・ユーザーの年月入力からカレンダーを表示させる

　・2026年以降が表示できるもの

　・閏年を考慮する

機能：

　・年月を入力してカレンダー表示
 
　・2001年を基準とし、それ以前の表示を制限する
 
　・前月・翌月への移動
 
工夫した点：

　・Dateオブジェクトの学習前だったため、別途曜日等を計算
 
　・CSSで前月/翌月移動ボタンを作成
 
　・月移動ボタンによる表示制限の注釈が表示されてもカレンダーの位置が変わらないようにレイアウト
